## About

**CHILL × QUEST** is a lightweight Discord Quest completion tool built around a simple idea:

**Less hassle. More chill.**

Designed with a clean interface, minimal setup, and a focus on making Discord quests straightforward.

## Features

* Discord Quest completion
* Lightweight and fast
* Clean dark interface
* Minimal setup
* Simple workflow
* CHILL × QUEST Hub
